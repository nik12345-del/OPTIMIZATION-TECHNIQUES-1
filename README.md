# Optimization of Single Variable Functions using First and Second Derivative Tests

## Aim
To determine the local minimum and maximum of a single-variable function using first and second derivative tests.

## Objective
- Understand unconstrained optimization.
- Apply first and second derivative tests.
- Find optimal points of a given function.

## Tools Used
- Python
- SymPy
- NumPy
- Jupyter Notebook / Google Colab

## Algorithm
1. Define the function.
2. Compute the first derivative.
3. Find critical points.
4. Compute the second derivative.
5. Determine whether each critical point is a local maximum or minimum.

## Output
- Function: `x³ - 6x² + 9x + 1`
- Local Maximum at **x = 1**
- Local Minimum at **x = 3**

## Conclusion
The first and second derivative tests successfully identified the local maximum and minimum points of the given function.
